# 🚀 Prompt Manager

Uma aplicação web leve e moderna criada para armazenar, organizar e copiar seus prompts de inteligência artificial de forma rápida e prática no dia a dia.

## 💻 Tecnologias utilizadas
- **HTML5** (Estrutura)
- **Tailwind CSS** (Estilização rápida e moderna)
- **JavaScript (Vanilla)** (Lógica, manipulação do DOM e interatividade)

## 📌 Funcionalidades
- Adicionar novos prompts com título e descrição.
- Botão de "Copiar" dinâmico com feedback visual instantâneo ("Copiado! 🎉").
- Interface limpa e responsiva.
